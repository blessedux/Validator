# Persona API - Documentation

DOB Validator uses the Persona API to improve account security. This documentation shows relevant information about the implementation, such as its endpoints and development TODOs.

** *Endpoints test WIP* **

## Persona endpoints

## API/PERSONA/

## CREATE INQUIRY

### DESCRIPTION
Creates a Persona Inquiry using the configured template and optional prefilled fields. Also creates a temporary link to start verification. This link is saved in db at the start and deleted at the end.

### ENDPOINT
`/persona/inquiry`

### METHOD

`POST`

### (JSON) PARAMETERS

| Parameter     | Type   | Requerided | Description                          |
| ------------- | ------ | ---------- | ------------------------------------ |
| `bearerToken` | string | yes        | Token generated by verified endpoint |

### POSIBLE RESULTS

## CORRECT REQUEST
```json
200 OK
{
    "result": {
        "data": {
            "type": "inquiry",
            "id": "<inquiryId>",
            "attributes": {
                "status": "created",
                "reference-id": "<userId>",
                "note": null,
            ...
            },
            "relationships": {...}
        }
    },
    "referenceId": "<userId>"
}
```
## ERROR CREATING LINK TO START VERIFICATION
```json
400 BAD REQUEST
{
    "error": "Error trying to create one-time-link"
}
```
## ERROR UPDATING INQUIRY ON DB
```json
400 BAD REQUEST
{
    "error": "Error trying to update inquiry in DB"
}
```
## ERROR WITH PERSONA API KEY
```json
400 BAD REQUEST
{
    "error": "Error with persona api key"
}
```
## BAD BEARER TOKEN
```json
401 UNAUTHORIZED
{
    "error": "Authorization header required"
}
```
## USER NOT FOUND
```json
404 NOT FOUND
{
    "error": "User not found"
}
```
## ERROR 
```json
500 INTERNAL SERVER ERROR
{
    "error": "Failed to create inquiry on persona"
}
```
## GET INQUIRY

### DESCRIPTION
Gets the latest inquiry by referenceID and updates the status in DB. Also checks one-time-link and update it.

### ENDPOINT
`/persona/inquiry`

### METHOD

`GET`

### (JSON) PARAMETERS

| Parameter     | Type   | Requerided | Description                          |
| ------------- | ------ | ---------- | ------------------------------------ |
| `bearerToken` | string | yes        | Token generated by verified endpoint |

### POSIBLE RESULTS

```json
{

  "updatedRows": 1
}
```

## Check Inquiry Status

### DESCRIPTION
This endpoint its used to find an inquiry by user encoded id. Its used to check inquiry status.

### ENDPOINT
`/persona/inquiry/inquiryID`

### (JSON) PARAMETERS

| Parameter     | Type   | Requerided | Description                          |
| ------------- | ------ | ---------- | ------------------------------------ |
| `bearerToken` | string | yes        | Token generated by verified endpoint |

### POSIBLE RESULTS

## INQUIRY RECEIVED
```json
200 OK
{
    "success": true,
    "<data>"
}
```
## ERROR TRYING TO UPDATE STATUS IN DB
```json
400 BAD REQUEST
{
    "error": "<inquiryStatus>, <dbUpdateError>"
}
```
## BAD BEARED TOKEN
```json
401 NOT AUTHORIZED
{
    "error": "Authorization header required"
}
```
## NOT FOUND ANY INQUIRY
```json
404 NOT FOUND
{
    "error": "No completed inquiry found for this referenceId: <referenceId>"
}
```
## ERROR
```json
500 INTERNAL SERVER ERROR
{
   "error": "Failed to filter inquiries"
}
```
