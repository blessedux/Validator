# Persona API - Documentation

DOB Validator uses the Persona API to improve account security. This documentation shows relevant information about the implementation, such as its endpoints and development TODOs.

** *Endpoints test WIP* **

## Persona endpoints

## API/PERSONA/

## CREATE INQUIRY

### DESCRIPTION
Creates a Persona Inquiry using the configured template and optional prefilled fields. Also creates a temporary link to start verification. This link is saved in db at the start and deleted at the end.

### ENDPOINT
`/persona/inquiry`

### METHOD

`POST`

### (JSON) PARAMETERS

| Parameter     | Type   | Requerided | Description                          |
| ------------- | ------ | ---------- | ------------------------------------ |
| `bearerToken` | string | yes        | Token generated by verified endpoint |

### POSIBLE RESULTS

## CORRECT REQUEST
```json
200 OK
{
    "result": {
        "data": {
            "type": "inquiry",
            "id": "<inquiryId>",
            "attributes": {
                "status": "created",
                "reference-id": "<userId>",
                "note": null,
            ...
            },
            "relationships": {...}
        }
    },
    "referenceId": "<userId>"
}
```
## BAD BEARER TOKEN
```json
401 UNAUTHORIZED
{
    "error": "Authorization header required"
}
```
## USER NOT FOUND
```json
404 NOT FOUND
{
    "error": "User not found"
}
```
## ERROR 
```json
500 INTERNAL SERVER ERROR
{
    "error": "Failed to upload file"
}
```
## GET INQUIRY

### DESCRIPTION
Gets the latest inquiry by referenceID and updates the status in DB. Also checks one-time-link and update it.

### ENDPOINT
`/persona/inquiry`

### METHOD

`GET`

### (JSON) PARAMETERS

| Parameter     | Type   | Requerided | Description                          |
| ------------- | ------ | ---------- | ------------------------------------ |
| `bearerToken` | string | yes        | Token generated by verified endpoint |

### POSIBLE RESULTS
## CORRECT REQUEST
```json
200 OK
{
  "status": "completed",
  "updatedRows": 1
}
```
## BAD BEARER TOKEN
```json
400 BAD REQUEST
{
    "error": "Error with persona api key"
}
```
## BAD BEARER TOKEN
```json
401 UNAUTHORIZED
{
    "error": "Authorization header required"
}
```
## USER NOT FOUND
```json
404 NOT FOUND
{
    "error": "User not found"
}
```
## INQUIRY NOT FOUND
```json
404 NOT FOUND
{
    "error": "No inquiries found for referenceID",
    "referenceID": "<referenceId>"
}
```
## ERROR 
```json
500 INTERNAL SERVER ERROR
{
    "error": "Failed to generate one-time link"
}
```

## Webhook Receiver

### DESCRIPTION
Webhook configured on persona API, receives status of inquiry and process it with handlePersonaWebhook function.
### ENDPOINT
`/webhook/persona/`

### METHOD

`POST`

### (JSON) PARAMETERS

NONE

### POSIBLE RESULTS

## WEBHOOK RECEIVED
```json
200 OK
{
    "status": "<newStatus>",
    "inquiryId": "<inquiryId>",
    "updatedAt": "<updatedDate>"
}
```
## WEBHOOK CANT FIND DATA
```json
404 NOT FOUND
{
    "error": "Missing required webhook data"
}
```
## ERROR
```json
500 INTERNAL SERVER ERROR
{
   "error": "Webhook processing failed"
}
```

### (JSON) PARAMETERS
