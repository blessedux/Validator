# Persona API - Documentation

DOB Validator uses the Persona API to improve account security. This documentation shows relevant information about the implementation, such as its endpoints and development TODOs.

## Persona endpoints

## API/PERSONA/

## CREATE INQUIRY

### DESCRIPTION
Creates a Persona Inquiry using the configured template and optional prefilled fields.

### ENDPOINT
`/persona/inquiry`

### METHOD

`POST`

### (JSON) PARAMETERS

| Parameter     | Type   | Requerided | Description                          |
| ------------- | ------ | ---------- | ------------------------------------ |
| `bearerToken` | string | yes        | Token generated by verified endpoint |

### POSIBLE RESULTS

## CORRECT REQUEST
```json
200 OK
{
    "result": {
        "data": {
            "type": "inquiry",
            "id": "<inquiryId>",
            "attributes": {
                "status": "created",
                "reference-id": "<userId>",
                "note": null,
            ...
            },
            "relationships": {...}
        }
    },
    "referenceId": "<userId>"
}
```
## BAD BEARER TOKEN
```json
401 UNAUTHORIZED
{
    "error": "Authorization header required"
}
```
## USER NOT FOUND
```json
404 NOT FOUND
{
    "error": "User not found"
}
```
## ERROR 
```json
500 INTERNAL SERVER ERROR
{
    "error": "Failed to upload file"
}
```
## GENERATE ONE-TIME LINK

### DESCRIPTION
Generates a one-time link for an existing Persona Inquiry.

### ENDPOINT
`/persona/inquiry/:inquiryId/generate-one-time-link`

### METHOD

`POST`

### (JSON) PARAMETERS

| Parameter   | Type   | Requerided | Description        |
| ----------- | ------ | ---------- | ------------------ |
| `inquiryId` | string | yes        | Persona Inquiry ID |

### POSIBLE RESULTS

## ONE-TIME LINK NOT GENERATED
```json
200 OK
{
    "link": "<oneTimeLink>"
}
```
## ONE-TIME LINK NOT GENERATED
```json
400 BAD REQUEST
{
    "error": "One-time link not found in Persona response"
}
```
## BAD BEARER TOKEN
```json
401 UNAUTHORIZED
{
    "error": "Authorization header required"
}
```

## ERROR 
```json
500 INTERNAL SERVER ERROR
{
    "error": "Failed to generate one-time link"
}
```

### DESCRIPTION

### ENDPOINT
`/persona/inquiry`

### METHOD

`GET`

### (JSON) PARAMETERS

| Parameter     | Type   | Requerided | Description                          |
| ------------- | ------ | ---------- | ------------------------------------ |
| `bearerToken` | string | yes        | Token generated by verified endpoint |

### POSIBLE RESULTS
## CORRECT REQUEST
```json
200 OK
{
  "status": "completed",
  "updatedRows": 1
}
```
## BAD BEARER TOKEN
```json

    "error": "Error with persona api key"

```
## BAD BEARER TOKEN
```json
401 UNAUTHORIZED
{
    "error": "Authorization header required"
```

## Webhook Receiver

### DESCRIPTION
Webhook configured on persona API, receives status of inquiry and process it with handlePersonaWebhook function.
### ENDPOINT
`/webhook/persona/`

### METHOD

`POST`

### (JSON) PARAMETERS

NONE

### POSIBLE RESULTS

## WEBHOOK RECEIVED
```json
200 OK
{
    "status": "<newStatus>",
    "inquiryId": "<inquiryId>",
    "updatedAt": "<updatedDate>"
}
```
## WEBHOOK CANT FIND DATA
```json
404 NOT FOUND
{
    "error": "Missing required webhook data"
}
```
## ERROR
```json
500 INTERNAL SERVER ERROR
{
   "error": "Webhook processing failed"
}
```
## Webhook To Redirect User

### DESCRIPTION
This endpoint uses **Webhook Receiver** endpoint to get the status of the inquiry and redirect the user to the appropriate page when persona verification is completed.

### ENDPOINT
`/webhook/persona/:referenceId`

### (JSON) PARAMETERS

| Parameter     | Type   | Requerided | Description                          |
| ------------- | ------ | ---------- | ------------------------------------ |
| `bearerToken` | string | yes        | Token generated by verified endpoint |

### POSIBLE RESULTS

## WEBHOOK RECEIVED
```json
200 OK
{
    "success": true,
}
```
## BAD BEARED TOKEN
```json
401 NOT AUTHORIZED
{
    "error": "Authorization header required"
}
```
## NOT FOUND ANY WEBHOOK
```json
404 NOT FOUND
{
    "error": "No completed webhooks found for this referenceId: <referenceId>"
}
```
## ERROR
```json
500 INTERNAL SERVER ERROR
{
   "error": "Failed to filter webhooks"
}
```
