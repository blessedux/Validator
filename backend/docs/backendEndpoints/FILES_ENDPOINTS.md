# Files Endpoints - Documentation

Dob validator needs to manage files to store devices documentation.


## Upload files

### DESCRIPTION
Receives any file type but only images with JPEG and PNG format then compress it to WebP. All files are stored in a secure location and file names are encrypted and loaded to db.

### ENDPOINT
`/api/files/upload`

### METHOD

`POST`

### (JSON) PARAMETERS

| Parameter     | Type    | Requerided          | Description                                 |
| ------------- | ------- | ------------------- | ------------------------------------------- |
| `bearerToken` | string | yes        | Token generated by verified endpoint   |
| `file` | file | yes        | File to upload formats accepted=JPEG/PNG/PDF MAX 10 FILES and 10MB each |

### POSIBLE RESULTS
## CORRECT REQUEST
```json
200 OK
{
    "status": "ok",
    "fileId": "<fileId>",
    "filename": "<filename>",
    "mimetype": "<mimetype>",
    "size": "<size>",
    "hash": "<hash>",
    "path": "<path>"
}
```
## NO FILE UPLOADED
```json
400 BAD REQUEST
{
    "error": "No file uploaded"
}
```
## BAD BEARER TOKEN
```json
401 UNAUTHORIZED
{
    "error": "Authorization header required"
}
```
## USER NOT FOUND
```json
404 NOT FOUND
{
    "error": "User not found"
}
```

## ERROR 
```json
500 INTERNAL SERVER ERROR
{
    "error": "Failed to upload file"
}
```


## Search File

### DESCRIPTION
All files are stored in a secure location and each one of them has a encrypted name, this endpoint search by those names into secure storage, returning the file.

### ENDPOINT
`/api/files/:id`

### METHOD

`GET`

### (JSON) PARAMETERS

| Parameter        | Type   | Requerided | Description                    |
| ---------------- | ------ | ---------- | ------------------------------ |
| `bearerToken` | string | yes        | Token generated by verified endpoint   |

### POSIBLE RESULTS

## CORRECT REQUEST
```json
200 OK
{
"Here shows image or file"
}
```
## BAD BEARER TOKEN
```json
401 UNAUTHORIZED
{
    "error": "Authorization header required"
}
```
## USER NOT FOUND
```json
404 NOTFOUND
{
    "error": "User not found"
}
```
## FILE NOT FOUND

```json
404 NOT FOUND
{
    "error": "File not found"
}
```
## FILE NOT FOUND ON LOCAL
```json
404 NOT FOUND
{
    "error": "File not found on disk"
}
```
## ERROR 
```json
500 INTERNAL SERVER ERROR
{
    "error": "Failed to fetch file"
}
```
